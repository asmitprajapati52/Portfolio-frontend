# Asmit Prajapati | Full-Stack Developer Portfolio

A modern, responsive portfolio built to showcase full-stack projects and technical skills. Designed for the 2026-2027 placement season.

## 🚀 Features
- **Project Gallery**: Showcases featured projects like Sahyata SOS and Lifeline360.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop using Tailwind CSS.
- **Real-time Contact**: Integrated with a Node.js/Express backend for instant email notifications.
- **Clean UI**: Minimalist aesthetic focusing on readability and professional branding.

## 🛠️ Tech Stack
- **Library**: React 18 (Vite)
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **HTTP Client**: Axios
- **Routing**: React Router DOM

## 📦 Installation
1. Navigate to the client directory: `cd client`
2. Install dependencies: `npm install`
3. Create a `.env` file in the root of the client folder:
   `VITE_API_URL=http://localhost:5000`
4. Start the development server: `npm run dev`
